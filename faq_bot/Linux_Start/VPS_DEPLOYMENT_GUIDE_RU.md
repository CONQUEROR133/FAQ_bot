# Пошаговое руководство по запуску FAQ Bot на VPS

## Введение

Это руководство поможет вам развернуть Telegram бот FAQ на сервере VPS с Ubuntu. Проект оптимизирован для работы на сервере со следующими характеристиками:
- Процессор: Intel Xeon 2 ГГц (1 ядро)
- ОЗУ: 512 МБ
- Диск: 10 ГБ HDD
- ОС: Ubuntu

## Шаг 1: Подготовка VPS

1. **Подключитесь к вашему VPS по SSH:**
   ```bash
   ssh root@ваш_IP_адрес
   ```

2. **Обновите систему:**
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```

## Шаг 2: Установка необходимых компонентов

1. **Установите Python и системные зависимости:**
   ```bash
   sudo apt install -y python3 python3-pip python3-venv build-essential libffi-dev
   ```

2. **Проверьте версию Python:**
   ```bash
   python3 --version
   ```
   Убедитесь, что версия 3.8 или выше.

## Шаг 3: Загрузка проекта

1. **Установите Git (если еще не установлен):**
   ```bash
   sudo apt install -y git
   ```

2. **Клонируйте репозиторий проекта:**
   ```bash
   git clone https://ваш_репозиторий.git
   cd faq_bot
   ```
   
   Или загрузите файлы проекта любым другим способом (например, через scp или sftp).

## Шаг 4: Настройка окружения

1. **Создайте виртуальное окружение:**
   ```bash
   python3 -m venv venv
   ```

2. **Активируйте виртуальное окружение:**
   ```bash
   source venv/bin/activate
   ```

3. **Обновите pip:**
   ```bash
   pip install --upgrade pip
   ```

4. **Установите зависимости проекта:**
   ```bash
   pip install -e .
   ```

## Шаг 5: Настройка конфигурации

1. **Создайте файл .env в корневой директории проекта:**
   ```bash
   nano .env
   ```

2. **Добавьте необходимые параметры конфигурации:**
   ```env
   BOT_TOKEN=ваш_токен_бота
   ADMIN_ID=ваш_телеграм_ID
   ACCESS_PASSWORD=ваш_пароль_доступа
   SIMILARITY_THRESHOLD=0.7
   BATCH_SIZE=8
   CACHE_SIZE=100
   EMBEDDING_CACHE_SIZE=200
   ```

   Замените значения на ваши собственные:
   - `BOT_TOKEN` - получите у @BotFather в Telegram
   - `ADMIN_ID` - ваш Telegram ID (можно узнать у @userinfobot)
   - `ACCESS_PASSWORD` - придумайте надежный пароль

3. **Сохраните файл (Ctrl+O, Enter, Ctrl+X в nano).**

## Шаг 6: Подготовка модели (если еще не сделано)

Если у вас уже есть обученные файлы модели ([faq_embeddings.pkl](file://d:\Games\faq_bot\cache\faq_embeddings.pkl) и [faq_index.faiss](file://d:\Games\faq_bot\cache\faq_index.faiss)), просто скопируйте их в директорию `cache/`.

Если файлов нет, обучите модель на более мощной машине и скопируйте файлы, так как обучение на VPS с 512 МБ ОЗУ может быть нестабильным.

## Шаг 7: Запуск бота

1. **Убедитесь, что вы находитесь в директории проекта и виртуальное окружение активировано.**

2. **Запустите бота:**
   ```bash
   python run_bot.py
   ```

   Или используйте подготовленный скрипт:
   ```bash
   ./Linux_Start/2_Start_Bot.sh
   ```

3. **Проверьте, что бот запустился без ошибок.**

## Шаг 8: Запуск бота в фоновом режиме (опционально)

Для запуска бота в фоновом режиме можно использовать systemd или screen.

### Вариант 1: Использование screen

1. **Установите screen:**
   ```bash
   sudo apt install -y screen
   ```

2. **Создайте сессию screen:**
   ```bash
   screen -S faq_bot
   ```

3. **Запустите бота:**
   ```bash
   python run_bot.py
   ```

4. **Отсоединитесь от сессии:**
   Нажмите `Ctrl+A`, затем `D`

5. **Для возврата к сессии:**
   ```bash
   screen -r faq_bot
   ```

### Вариант 2: Использование systemd (рекомендуется)

1. **Создайте файл сервиса:**
   ```bash
   sudo nano /etc/systemd/system/faq_bot.service
   ```

2. **Добавьте следующее содержимое:**
   ```ini
   [Unit]
   Description=FAQ Bot Service
   After=network.target

   [Service]
   Type=simple
   User=ваш_пользователь
   WorkingDirectory=/путь/к/вашему/проекту/faq_bot
   ExecStart=/путь/к/вашему/проекту/faq_bot/venv/bin/python run_bot.py
   Restart=always
   RestartSec=10

   [Install]
   WantedBy=multi-user.target
   ```

   Замените `ваш_пользователь` и `/путь/к/вашему/проекту/faq_bot` на актуальные значения.

3. **Перезагрузите systemd:**
   ```bash
   sudo systemctl daemon-reload
   ```

4. **Включите автозапуск сервиса:**
   ```bash
   sudo systemctl enable faq_bot.service
   ```

5. **Запустите сервис:**
   ```bash
   sudo systemctl start faq_bot.service
   ```

6. **Проверьте статус сервиса:**
   ```bash
   sudo systemctl status faq_bot.service
   ```

Если вы обновили файл `data/faq.json`, вам нужно пересоздать модель:

1. **Остановите бота (если запущен).**

2. **Запустите обучение модели:**
   ```bash
   python train_model.py
   ```
   
   Или используйте подготовленный скрипт:
   ```bash
   ./Linux_Start/1_Train_Model.sh
   ```

3. **Запустите бота снова.**

## Решение проблем

### Бот не запускается

1. **Проверьте логи:**
   ```bash
   cat cache/bot.log
   ```

2. **Убедитесь, что все зависимости установлены:**
   ```bash
   pip install -e .
   ```

3. **Проверьте файл .env на наличие ошибок.**

### Ошибки памяти

Если вы сталкиваетесь с ошибками памяти:
1. Убедитесь, что BATCH_SIZE установлен в 8 в файле .env
2. Проверьте использование памяти:
   ```bash
   free -h
   ```

### Проблемы с подключением к Telegram

1. **Проверьте правильность BOT_TOKEN в .env**
2. **Убедитесь, что бот не заблокирован в Telegram**
3. **Проверьте сетевые настройки VPS (firewall, порты)**

## Оптимизация для ограниченных ресурсов

1. **Размер батча**: Установлен в 8 для уменьшения использования памяти
2. **Размер кэша**: Уменьшен до 100/200 элементов
3. **Очистка временных файлов**: Регулярно удаляйте ненужные файлы, но сохраняйте модель
4. **Мониторинг ресурсов**: Используйте скрипт проверки статуса для мониторинга
